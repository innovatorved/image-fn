Documentation

ImageFn is a URL-only Bun.Image transform server with a static editor UI. No storage, R2 bucket, or AWS dependency — transforms are driven entirely by query parameters.

How to use

Web editor

  1. Open the editor at /.
  2. Paste an HTTPS image URL in Source.
  3. Set width, height, fit, rotate, format, and quality under Transform.
  4. Click Apply transform to preview the result.
  5. Copy the image URL, editor link, or download the output from Share.

Image URL vs editor URL

Both URLs use the same query string. Only the path changes:

  • /i?... — returns transformed image bytes (use in <img> tags).
  • /?... — opens the editor with the same settings pre-filled.
# Embed the transformed image
/i?url=https%3A%2F%2Fexample.com%2Fphoto.jpg&w=800&fmt=webp&q=80

# Reopen the same edit in the UI
/?url=https%3A%2F%2Fexample.com%2Fphoto.jpg&w=800&fmt=webp&q=80

Common examples

Resize to 1200px wide, keep aspect ratio:

/i?url=https%3A%2F%2Fexample.com%2Fphoto.jpg&w=1200&fit=inside&fmt=webp&q=82

Square cover crop:

/i?url=https%3A%2F%2Fexample.com%2Fphoto.jpg&w=600&h=600&fit=fill&fmt=jpeg&q=85

Let the server pick the best format from the browser Accept header:

/i?url=https%3A%2F%2Fexample.com%2Fphoto.jpg&w=900&fmt=auto&q=80

API usage

Transform image

GET /i?url=<https-image-url>&w=800&h=600&fit=inside&rot=90&fmt=webp&q=80

Legacy /api/image?... redirects to /i?... with 308.

ParamDescription
urlRequired HTTPS source image URL
w, hOutput width/height from 1 to 12000
fitpad (default) fits inside the box on a white canvas; inside fits without padding; fill crops/stretches to cover
withoutEnlargementtrue never upscales during resize
filterResize kernel: lanczos3 (default), mitchell, box, etc.
rotRotate by 90, 180, or 270
fliptrue flips vertically
floptrue flips horizontally
fmtwebp, jpeg, jpg, png, avif, or auto
qQuality 1–100 (ignored for PNG)
brightnessOptional 0–3 (Bun.Image modulation)
saturationOptional 0–3 (Bun.Image modulation)
placeholder=trueReturns JSON with a tiny blurred data URL

Health check

GET /api/health

Returns status, runtime, engine, storage, and configured pixel/cache limits.

Deployment

Local development

bun install
cp .env.example .env
bun run dev

Open http://localhost:8787. Use bun run start for a non-watch server.

Docker build and run

Build the image:

docker build -t image-fn .
# or
bun run docker:build

Run the container on port 8787:

cp .env.example .env
docker run --rm -p 8787:8787 --env-file .env image-fn
# or
bun run docker:run

The Docker image includes a healthcheck against /api/health. Verify manually:

curl http://localhost:8787/api/health
Production: Put the container behind HTTPS at your load balancer. Restrict ALLOWED_HOST_SUFFIXES to known image hosts. The in-memory cache is per-container and resets on restart.

Security and limits

  • Source URLs must be HTTPS. Localhost, private IPs, link-local, .local, and .internal hosts are blocked.
  • Remote fetches respect MAX_SOURCE_BYTES, decode respects MAX_IMAGE_PIXELS, and output respects MAX_OUTPUT_PIXELS.
  • Source fetches time out after SOURCE_FETCH_TIMEOUT_MS.
  • The app is stateless — no persistent volume required.
